# loaf

Homebrew installs for [loaf](https://tryloaf.app).

```sh
brew install --cask tryloaf/loaf/loaf
```

for macOS 15.4 and later, on Apple Silicon or Intel. downloads come from `downloads.tryloaf.app`, with a pinned checksum. loaf updates itself through Sparkle; the terms are shown on first launch.

this repo contains the install recipe. loaf’s [license](https://tryloaf.app/license) applies to the app.
